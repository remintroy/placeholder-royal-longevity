# Royal Longevity

A responsive React coming-soon page, built with Vite.

## Development

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

Deploy the generated `dist/` directory to a static hosting provider and connect your domain through that provider's DNS instructions.

The page uses Google Fonts with local serif and sans-serif fallbacks. It does not collect visitor data or require a backend.
